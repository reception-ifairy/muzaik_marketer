# Gdy coś nie działa

Najczęstsze komunikaty i co z nimi zrobić.

**Gdzie:** cała aplikacja · **Potrzebne:** nic

| Komunikat | Co zrobić |
| --- | --- |
| „brak połączenia” przy muzaik.channel | Aplikacja nie widzi bazy kanału. Sprawdź, czy działa na serwerze muzaik i ma ustawioną ścieżkę bazy ([wdrożenie](#docs/wdrozenie)). |
| „… to cover — do materiałów na YouTube idą tylko utwory autorskie” | Wybierz utwór autorski. Jeśli to pomyłka w karcie, zmień rodzaj w kartach utworów muzaik.channel. |
| „Nie mam pliku tego utworu” | Wgraj plik w Studiu albo dodaj klucz AzuraCast ([Ustawienia](#handbook/ustawienia)). |
| „Model nie oddał poprawnego planu” | Spróbuj jeszcze raz albo zmień silnik w Ustawieniach. |
| „Renderuje się inny materiał” | Montaż idzie po jednym. Poczekaj na koniec. |
| „Render przerwany (restart aplikacji)” | Aplikacja była restartowana w trakcie. Zmontuj jeszcze raz. |
| „Token nie należy do kanału MuzaIK” | Połącz ponownie i w oknie Google wybierz kanał MuzaIK. |
| „Dostęp do YouTube wygasł” | Ustawienia → YouTube → Połącz ponownie. |

> **Nie rób tego.** Nie wgrywaj do materiałów coverów ani cudzych nagrań przez „Wgraj plik utworu” — plik zostanie przypisany do wybranej karty autorskiej.
